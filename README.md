------------------------------------------------------------
---------------------双人联机打砖块游戏-----------------------
------------------------------------------------------------
**项目简介**
本项目是基于 C++、Raylib 图形库与 ENet 网络库开发的 2D 打砖块游戏，实现了完整的游戏逻辑、多关卡递进、难度递增、游戏存档/读档、双人联机、道具系统、粒子特效、异步加载等功能。项目遵循面向对象设计思想，在 Linux 环境下完成开发，是一次完整的 C++ 工程实践。

### 环境依赖
- Ubuntu / WSL
- C++17 及以上
- Raylib
- ENet
- nlohmann/json
 
### 编译命令
```bash
g++ main.cpp breakoutgame.cpp -o breakout -lraylib -lGL -lm -lpthread -ldl -lrt -lX11 -lenet
``` 

### 运行命令
``` bash
./breakout
```

### 操作命令
- 移动下方挡板->鼠标
- 发射球->鼠标左键
- 控制上方挡板->方向键 ← →
- 开始游戏->空格
- 重新开始->R
- 保存游戏进度->S
- 异步加载资源->L
- 读取存档继续游戏->1
- 全新开局->2

### 功能列表
- BASE:基础打砖块游戏逻辑
- 三关卡递进，难度自动提升
- 球速逐关加快，挡板速度逐关减慢
- 关卡配置文件：level.json
- 游戏存档与读档：save.json
- 双人联机对战
- 道具系统（挡板延长、多球、球减速）
- 粒子特效
- 多线程异步资源加载
- 游戏状态网络同步
- 分数、生命值、当前关卡 UI 显示
